O QUE LIMPAR SÓ IMAGENS CRIADAS HÁ MAIS DE (HORAS) 0 não filtra por idade. O runtime olha a data de criação da imagem, não a do último uso: as imagens base antigas continuam elegíveis. MANTER O CACHE USADO NAS ÚLTIMAS (HORAS) 0 remove todo o cache sem uso. Com um prazo, o cache de um job ou deploy recente sobrevive e o próximo build não recomeça do zero. Depois de limpar, reconstrói a imagem de cada serviço com repositório Git ou zip, um de cada vez, na fila de deploy. Sem isso, o primeiro deploy depois da limpeza paga o build inteiro.
VOLUMES — CUIDADO Volumes sem uso criados por fora do rustploy (não pelos seus serviços, que só usam bind mount) podem conter dado que ninguém recriaria sozinho. Confirme que sabe o que existe no host antes de ativar.
